# CADLito

CAD-Zeichnen mit **Aufmaß** (Positionen, GAEB-Import, Maßstab kalibrieren, Formen mit Rechenweg, Export als GAEB DA XML X31, CSV und Aufmaßblatt). Basiert auf CADCraft (MIT OR Apache-2.0).

Nur fertige Setups, kein Quellcode. Installation und Updates erledigt der **Lito Launcher**. Manuell: unter **Releases** `CADLito-Setup-<Version>.exe` laden und doppelklicken (je Benutzer, ohne Administratorrechte). Prüfsumme: `SHA256SUMS.txt`.
